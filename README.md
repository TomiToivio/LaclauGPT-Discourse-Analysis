# LaclauGPT 

LaclauGPT is a social science data collection and analysis pipeline. It is called LaclauGPT as a tribute to [Ernesto Laclau](https://en.wikipedia.org/wiki/Ernesto_Laclau). LaclauGPT is developed by [Tomi Toivio](mailto:tomi.toivio@helsinki.fi).

This repository also contains a draft of the related paper. 

This version is based on two older repositories:
[LaclauGPT TikTok Scraper](https://github.com/TomiToivio/LaclauGPT-TikTok-Scraper)
[LaclauGPT Multimodal Analysis](https://github.com/TomiToivio/LaclauGPT-multimodal-analysis)
