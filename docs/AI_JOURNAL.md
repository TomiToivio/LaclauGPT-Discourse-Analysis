# AI Journal — daily paper & repo journal

**Issue #93**: *Daily paper & repo journal* — a public journal documenting the
state of the paper and repository for an outside reader. Entries may include
canonical paper state, public repository changes, and epistemic or
methodological observations.

The paper is never edited through this journal; the canonical source is
mirrored to `paper/PAPER.md` in this repository.

Publication rule: this journal records research and software decisions, not
machine-local operations. Hostnames, private network addresses, credentials,
account names, filesystem paths, live service status, private source lists,
backup details and other deployment-specific information stay outside Git.
